# Siril

[Siril](https://siril.org) built from source on Alpine for headless use:
`siril-cli -d <workdir> -s <script.ssf>`.

Built with XISF, FITS, PNG/JPEG/TIFF and libcurl (online star catalogues
for plate solving); video, camera raw, HEIF/JXL, EXIF and the git script
repository are left out. amd64 only.
